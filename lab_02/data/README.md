# Lab 02 protected requirements

This folder contains no MRI images.

- `architecture_requirements.json` records the fixed workflow-part names, case
  names, and boundary rules used by every team.
- `checksums.sha256` protects that file from accidental changes.

Running `lab.py start` creates `outputs/architecture_start_check.json`. That
generated JSON links the Lab 02 work to the checked Lab 01 brief and confirms
that no dataset images were loaded.

Students do not edit files in this folder.
